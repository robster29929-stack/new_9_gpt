# ระบบ 03 — คลังบทเรียนและข้อสอบ

## สถานะ

เป็นต้นแบบ UI ใน private Site ใช้ข้อมูลโครงสร้าง `TEST_` เท่านั้น ระบบรวม 3 คลังไว้ในเมนูเดียว ได้แก่ นักธรรม ธรรมศึกษา และบาลี มีโครงรายวิชา 68 รายการ: นักธรรม 12, ธรรมศึกษา 36 (9 ช่วงชั้น × 4 วิชา), บาลี 20 รายการ

ยังไม่มีข้อสอบ คำถาม ตัวเลือก เฉลย คะแนนจริง ใบอนุญาตใช้เนื้อหา หรือ rubric ที่เจ้าของวิชารับรอง จึงยังไม่เปิดทำแบบทดสอบจริง ปุ่ม “ก่อนเรียน” และ “หลังเรียน” ใช้ตรวจสถานะความพร้อมและแสดงเหตุผลที่ยังเปิดไม่ได้เท่านั้น ไม่สร้างผลสอบหรือคะแนน

### 9 ช่วงชั้นธรรมศึกษา

| ระดับการศึกษา | ชั้นตรี | ชั้นโท | ชั้นเอก |
|---|---|---|---|
| ประถมศึกษา | ธรรมศึกษาชั้นตรี · ระดับประถมศึกษา | ธรรมศึกษาชั้นโท · ระดับประถมศึกษา | ธรรมศึกษาชั้นเอก · ระดับประถมศึกษา |
| มัธยมศึกษา | ธรรมศึกษาชั้นตรี · ระดับมัธยมศึกษา | ธรรมศึกษาชั้นโท · ระดับมัธยมศึกษา | ธรรมศึกษาชั้นเอก · ระดับมัธยมศึกษา |
| อุดมศึกษา | ธรรมศึกษาชั้นตรี · ระดับอุดมศึกษา | ธรรมศึกษาชั้นโท · ระดับอุดมศึกษา | ธรรมศึกษาชั้นเอก · ระดับอุดมศึกษา |

ชื่อช่วงชั้น 9 แบบยึดโครงหลักสูตรธรรมศึกษาที่แบ่งตรี–โท–เอก × ประถมศึกษา–มัธยมศึกษา–อุดมศึกษา รายการหมวดวิชาในต้นแบบแยกตามชั้นดังนี้: **ตรี** — เรียงความแก้กระทู้ธรรม, ธรรม, พุทธประวัติ, วินัย (เบญจศีล-เบญจธรรม); **โท** — เรียงความแก้กระทู้ธรรม, ธรรม, พุทธานุพุทธประวัติ, วินัย (อุโบสถศีล); **เอก** — เรียงความแก้กระทู้ธรรม, ธรรม, พุทธานุพุทธประวัติ, วินัย (กรรมบถ) อ้างชื่อตามรายการคู่มือในหน้า download และหมวดข้อสอบที่เปิดตรวจ ต้องยืนยันว่าชื่อวิชาและฉบับหลักสูตร/ปีที่ใช้ตรงกันทั้งสามช่วงการศึกษากับเจ้าของหลักสูตรก่อนใช้เป็น catalog ทางการ

## แบบทดสอบและการปล่อยเนื้อหา

ก่อนเปิดให้ผู้เรียนทำแบบทดสอบจริง ต้องมีข้อมูลต่อไปนี้และได้รับอนุมัติตาม policy ขององค์กร:

1. หลักสูตร/ชั้น/วิชาที่ใช้กับปีการศึกษาหรือปีสอบใด พร้อมเอกสารอ้างอิงและเจ้าของเนื้อหา
2. ชุดคำถามก่อนเรียนและหลังเรียนแยกประเภท พร้อม revision, เฉลยหรือแนวตรวจ, คะแนนเต็ม, เวลา และเกณฑ์สุ่ม/ลำดับข้อที่ยืนยันแล้ว
3. rubric และการตรวจโดยครูสำหรับงานแปล/แต่ง รวมกระบวนการทบทวน/อุทธรณ์ถ้ามี
4. ผู้อนุมัติเผยแพร่และสิทธิ์ถอน release; การเผยแพร่สาธารณะต้องใช้ field allowlist และแผนถอน cache
5. นโยบายเก็บ/ลบ attempt และคะแนนฝึกเรียน ซึ่งต้องแยกจากบัญชี ศ.2/ศ.3 และผลสอบทางการ

สถานะงานที่ออกแบบ: `draft → review → approved release → retired/revoked` เป็นเพียงแนว lifecycle สำหรับยืนยัน ไม่ใช่ workflow หรืออำนาจอนุมัติที่องค์กรรับรองแล้ว

## พจนานุกรมข้อมูลต้นแบบ

| ฟิลด์ | ความหมาย | สถานะ/ข้อควบคุม |
|---|---|---|
| `id` | รหัสชุดรายวิชา | `TEST_` ในต้นแบบ; production ต้อง unique constraint |
| `domain` | ประเภทคลัง เช่น `TEST_นักธรรม`, `TEST_ธรรมศึกษา`, `TEST_บาลี` | ใช้เลือกเนื้อหาและสิทธิ์ตามโมดูล/ขอบเขต |
| `track` | คีย์คลังย่อย | `naktham`, `dhamma-studies`, `pali` ใน UI prototype |
| `level` | ชั้นหรือประโยค | ต้องผูกกับหลักสูตร/ปีที่เจ้าของยืนยันก่อนใช้งานจริง |
| `subject` | รายวิชา | label จาก scope และ reference ที่ระบุใน SOURCE_PROFILE; ยังไม่ใช่หลักสูตรอนุมัติ |
| `lessons` | แหล่งบทเรียน/เนื้อหา | `TO VERIFY` จนมี source และสิทธิ์ใช้งาน |
| `questionBank` | รุ่นคลังข้อสอบที่เผยแพร่ | “ยังไม่มีชุดที่รับรอง” ใน prototype |
| `rubric` | เกณฑ์ตรวจงานเขียน/แปล/แต่ง | `รอยืนยัน`; ห้ามใช้คะแนน/เกณฑ์สมมติ |
| `ExamSession` | รอบสอบทางการที่อาจอ้างอิง | แยกจากแบบทดสอบเรียน; ห้ามอนุมานกำหนดการหรือผลสอบ |

## เงื่อนไขตรวจรับต้นแบบ

- เลือกคลังนักธรรม ธรรมศึกษา หรือบาลีได้ โดยยังอยู่ในเมนูระบบ 03 เดียวกัน
- นักธรรมแสดงชั้นตรี–โท–เอก; ธรรมศึกษาแสดง 9 ช่วงชั้นจากชั้นตรี–โท–เอก คูณระดับประถม–มัธยม–อุดม และ 4 หมวดวิชาตามชั้น; บาลีแสดง 8 กลุ่มชั้นประโยคและ 20 คู่ชั้น–วิชา
- ทุกวิชามีช่องทางก่อนเรียน/หลังเรียน และแสดงข้อความล็อกพร้อมเหตุผลเมื่อยังไม่มี release ที่รับรอง
- แยกคะแนนฝึกเรียนจากผลสอบทางการ และไม่ตีความการค้นไม่พบว่า “สอบตก”
- นำเข้า/ส่งออก Excel ได้เฉพาะข้อมูลทดสอบ; ไม่มีการนำเข้าข้อสอบทางการหรือเผยแพร่เนื้อหาจริงใน prototype
- ค้น/กรองรายวิชาและ pagination อยู่ใน browser memory; production ต้องใช้ server-side pagination และตรวจ role+scope ที่ server/DB ทุกคำขอ

## ข้อจำกัด

เว็บไซต์ยังเป็น static browser-only prototype ไม่มี auth, backend, persistence, RLS, audit หรือการอนุมัติจริง ปุ่มประเมินไม่ใช่แบบทดสอบที่เล่นได้จนกว่าจะได้รับชุดเนื้อหาที่อนุมัติ
