## สรุปการใช้งานแหล่ง

หน้า NBMS ที่ผู้ใช้ระบุไม่ตอบสนองต่อการดึงข้อมูลในรอบตรวจนี้; ผลค้นหาจากรายการกรมบัญชีกลางระบุเรื่องเงินนอกงบประมาณ จึงอนุมานว่า scope ของ NBMS อาจไม่ครอบคลุมงบทุกประเภท และยังต้องให้เจ้าของนโยบายยืนยัน ไม่คัดลอก role, workflow, สูตร, เอกสาร หรืออำนาจจาก NBMS มาเป็น policy ของพอร์ทัล ต้นแบบทำตามรายการความสามารถที่ผู้ใช้ระบุโดยแสดง TEST_ และลงประเด็นเจ้าของ/หลักฐานที่ต้องยืนยันไว้ใน `docs/OPEN_QUESTIONS.md`
