หลักฐานค้นเว็บที่เก็บในบันทึกงาน: ผลค้น `e-Office` และคู่มือทางการแสดงคำอธิบายเรื่องรายงานรับ–ส่ง/Excel, ร่างและแนบไฟล์, ส่งตรวจ, เสนอลงนาม, ส่ง/รับ และสถานะปฏิเสธการรับ หน้าอ้างอิงบางหน้าเปิดตรงไม่สำเร็จจาก timeout จึงไม่ใช้ตีความกฎทางกฎหมายหรือวิธีปฏิบัติที่มีผลบังคับ

## ขอบเขตที่อนุมานได้

- UX ควรแยกงานร่าง กล่องรับ กล่องส่ง การรับทราบ/ตีกลับ รายละเอียด และประวัติ
- งานตรวจทาน ลงนาม ออกเลขทะเบียน และส่งออกภายนอกเป็น capability ที่ต้องมี policy และหลักฐานแยก ไม่ใช่ action ที่อนุมานจากชื่อบทบาท
- Export ต้องผ่าน permission และ field allowlist; เอกสารลับ/จำกัดสิทธิ์ไม่ควรอยู่ใน public release หรือไฟล์ export ทั่วไป
- จดหมายเวียนควรสร้าง preview แยกตามผู้รับและให้ตรวจทานก่อนส่ง; prototype ปัจจุบันสร้างเพียงร่างแยกโดยยังไม่เชื่อมการส่ง

ข้อสรุป UX ข้างต้นเป็นการออกแบบจากคู่มือผลิตภัณฑ์ตัวอย่าง ไม่ใช่คำยืนยันว่าเจ้าของโครงการได้เลือก e-Office, dConnect, รูปแบบเลขทะเบียน, ลายมือชื่ออิเล็กทรอนิกส์ หรือกระบวนการใด
