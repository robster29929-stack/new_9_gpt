## หลักฐานที่ใช้ในต้นแบบ

- ใช้ ศ.2 เป็น form type สมัครบาลี; แสดง ศ.3 เป็นบัญชีเรียกชื่อ/เอกสารดำเนินการสอบตามเส้นทางส่วนภูมิภาคที่ตรวจพบ
- รองรับคำค้นปีการศึกษา ชั้น/ประโยค ชื่อ วัด สำนักเรียน/จังหวัด และเลขลำดับ โดยในต้นแบบรับเฉพาะ token `TEST_`
- ผลสอบในหน้าเว็บเป็นศูนย์รายการและไม่มีข้อมูลจริง; ไม่พบชื่อไม่แปลว่าสอบตก
- ฟิลด์ PII ที่เห็นใน PDF ใช้ประกอบ data-design เท่านั้น; ไม่สร้างช่องหมายเลขบัตร/อายุ/ผลสอบให้ผู้ใช้ทดลองกรอกใน UI
