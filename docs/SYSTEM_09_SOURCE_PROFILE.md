## ผลกระทบต่อ UI

- ตัวเลือกนักธรรมชั้นตรีแสดง ศ.1 ตามหน้าแบบฟอร์มที่ตรวจพบ พร้อมหมายเหตุว่าคำขอระบุ ศ.1–2 ซึ่งยังต้องยืนยัน
- ศ.2 สำหรับนักธรรมแสดงเป็นตัวเลือกเดียว “ชั้นโท–เอก” แต่แต่ละแถวต้องมีชั้นที่ระบุชัด
- ศ.5 และ ศ.6 แยกธรรมศึกษาชั้นตรีกับชั้นโท–เอก
- ระบบยังใช้ schema นำเข้า TEST_ กลาง ไม่อ้างว่าเป็นรูปแบบทางการ

## ไฟล์แนบจากผู้ใช้ที่ตรวจเพิ่ม 16 ตุลาคม 2026

- ได้รับไฟล์รายชั้นครบ 6 ไฟล์: นักธรรม ศ.1 ชั้นตรี; ศ.2 ชั้นโท/เอก; ธรรมศึกษา ศ.5 ชั้นตรี; ศ.6 ชั้นโท/เอก
- เปิดอ่าน workbook `.xls` ได้ครบทุกไฟล์ โดยแต่ละไฟล์มี 1 sheet; พบค่าที่กรอกในพื้นที่รายการของทุกไฟล์; ไม่แก้ไขต้นฉบับ
- เพิ่มดาวน์โหลดแยกตามชั้นไว้ใน System 09; รายชื่อ sheet, ขนาด, hash และข้อจำกัดอยู่ใน `docs/DOWNLOADABLE_FORMS.md`
- หน้ารายการดาวน์โหลดเตือนว่าไฟล์มีค่ากรอกและเว็บไซต์จำกัดผู้เข้าถึงเฉพาะเจ้าของตาม policy เดิม; ไม่ใช้ไฟล์เหล่านี้กับ importer ที่รับ TEST_ กลาง
- ไฟล์แนบไม่ได้ยืนยันว่า 2568-v3 ยังเป็น revision ที่หน่วยงานรับอยู่, ไม่ยืนยัน field mapping/validation หรืออำนาจให้เผยแพร่ต่อ; ติดตาม OQ-09-01/02/05
