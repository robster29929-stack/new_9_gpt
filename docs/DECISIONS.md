## D-006-01 — ทำวงจรงบประมาณเป็นขั้นตอนในระบบเดียว

- วันที่: 2026-10-15
- สถานะ: การตัดสินใจสำหรับต้นแบบ TEST_ เท่านั้น; ไม่ใช่การอนุมัติระบบบัญชีหรืออำนาจทำรายการ
- การตัดสินใจ: System 06 แสดงภาพรวม แผน/จัดสรร โอน ผูกพัน เบิกจ่าย/จ่ายจริง คืนเงิน กระทบยอด และปิดงวด; ตัวเลขเก็บเป็น integer satang, ปีงบประมาณแยกจากปีการศึกษา และร่างทำงานเฉพาะใน memory
- หลักการคำนวณ: `ยังไม่ผูกพัน = จัดสรร − ผูกพัน`; `ผูกพันค้างจ่าย = ผูกพัน − จ่ายจริง`; ยอดจ่ายเป็นส่วนหนึ่งของยอดผูกพันจึงไม่หักซ้ำ; transfer แสดง source/destination; refund รอตรวจไม่เปลี่ยนยอดจริง
- หลักฐานประกอบ: `docs/SYSTEM_06_SOURCE_PROFILE.md`; หน้าอ้างอิง NBMS ดึงตรงไม่สำเร็จและรายการกรมบัญชีกลางแสดงชื่อระบบเงินนอกงบประมาณ; คู่มือ New GFMIS Thai แจกแจง FM, PO, AP, RP, FA, GL และ MIS แยกกัน
- ข้อจำกัด: ไม่สมมติว่าหน่วยงานใช้ NBMS/GFMIS, ไม่สมมติผังบัญชี/ผู้มีอำนาจ/สถานะ/เอกสาร และไม่สร้างอนุมัติหรือปิดงวดจริง; ยืนยันก่อนทำ backend/migration ตาม OQ-06
