| --- | --- | --- | --- |
| [Pasadu Prompt](https://pasadu.vercel.app/) | ได้ผลจากดัชนีค้นเว็บ; การเปิดหน้าโดยตรงจากเครื่องมืออ่านเว็บในรอบนี้ตอบ `DisabledError` | หน้าแนะนำระบบกล่าวถึงคลัง 2 ระดับ, เบิกหลายรายการ/อนุมัติเป็นชุด, ทะเบียนครุภัณฑ์และการติดตามซ่อม, Stock Card และรายงาน | เป็นคำอธิบายของผู้ให้บริการ ไม่ใช่หลักฐานขั้นตอนหรือสิทธิ์ของหน่วยงานผู้ใช้ |

ผลค้นที่อ้างอิง: `turn37search0` และ `turn37search2` (ดึงข้อมูลจากดัชนีเมื่อ 2026-10-15) รายละเอียดที่เปลี่ยนได้ เช่น ราคา จำนวนหน่วยงาน สถิติ ความพร้อมใช้ หรือคุณสมบัติแพ็กเกจ ไม่นำมาใช้กำหนดขอบเขตหรือข้อเท็จจริงของโครงการนี้

## การนำมาใช้ใน prototype

- ใช้แนวคิดแยกคลัง/หน่วยงาน, หน้าประวัติ movement, รับเข้า/เบิก/คืน/โอน/ยืม/ซ่อม/ตรวจนับ/จำหน่าย และ preview ก่อน import
- เพิ่มคำขอจัดซื้อและ reference ไปยังแผนงบระบบ 06 ของโครงการนี้; การเชื่อมเป็น TEST_ เท่านั้น
- แยก `Asset` ออกจาก `StockMovement`; จำนวนคงเหลือได้จาก movement ไม่ใช่จำนวนที่แก้ตรงในทะเบียน
- ไม่คัดลอกแบรนด์ เนื้อหา ภาพ ลำดับหน้าจอ หรือข้อความของเว็บอ้างอิง
- ไม่จำลองบทบาทผู้อนุมัติเป็นอำนาจองค์กร; ทุกการยืนยันในต้นแบบเป็นการทดลองบันทึกใน browser memory
